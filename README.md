# Современный Колизей — Step 1

Первый шаг portfolio-проекта: быстрый и доступный hero-экран без тяжелой графики.

## Почему так

- Сначала фиксируем UX и семантику, затем добавляем визуальные эффекты.
- Кнопка входа — настоящий `button`, доступный с клавиатуры.
- `prefers-reduced-motion` заложен сразу.
- `100svh` корректнее ведет себя на мобильных браузерах.
- Фон сейчас CSS-заглушка. На следующем шаге заменяется на оптимизированный hero-арт Колизея.

## Запуск

```bash
npm install
npm run dev
```
